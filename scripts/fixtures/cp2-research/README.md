# CP2 research synthetic fixtures

Every file here is a fictional software test input, never CP2 evidence. Counts, categories, future dates, XTS test currency and reserved `.test`/`.invalid` source domains have no research meaning. No real participants, companies, prices, market facts or source fetches were used.

`survey-valid.csv` tests multiple questions and multi-select denominators; `survey-valid.json` tests the equivalent JSON row schema. Negative fixtures deliberately contain a reserved-domain email, fictional reserved phone number, malformed CSV, missing URL, unsupported claim or missing pricing context. These strings must be rejected without being printed. Never import any fixture into the evidence register or present it as a collected finding.
