## Evidence handling rules

1. Give each item a unique ID: `TU-###` for target-user interview, `EX-###` for expert interview, `SV-###` for survey summary, `CM-###` for competitor/market source, or another documented prefix.
2. Record the actual collection/source date, not the date this template was made.
3. Write an anonymized summary that separates observation/source facts from interpretation.
4. Link the relevant hypothesis and classify the signal as supporting, neutral, or contradicting. This classification is a review aid, not proof.
5. Record limitations, confidence, and owner review status before a claim is used publicly.
